# ด่านตรวจ

33 ชุด สะสมมา 15 รอบ ทุกชุดเขียนขึ้นเพราะมีของจริงพังหรือเกือบพัง
ไม่ใช่เทสต์ที่เขียนเพื่อให้มีเทสต์

**เส้นฐาน: 10 ส.ค. 2569 — รันจากรีโปแล้วเขียวครบ 33/33 ชุด**
ถ้ารอบหน้ามีชุดไหนแดงโดยที่ยังไม่ได้แก้อะไร แปลว่าสภาพแวดล้อมเปลี่ยน ไม่ใช่โค้ดพัง
(ตัวช้าสุดคือ `nohscroll` ~370 วินาที · `deal-r10` ~165 · `leave-r10` ~140 · รวมทั้งหมด ~10-15 นาทีที่ 3 งานพร้อมกัน)

## รัน

```bash
node tools/qa/run.js                 # ทุกชุด ~10-15 นาที
node tools/qa/run.js geo clock       # เฉพาะชุดที่ชื่อมีคำนี้
node tools/qa/run.js --list          # ดูรายชื่อ
node tools/qa/run.js --jobs 1        # ทีละชุด (ค่าเริ่มต้น 3)
```

ตัวรันเปิดเซิร์ฟเวอร์ static ที่ 8123 **จาก repo root** ให้เอง แล้วปิดให้ตอนจบ
ถ้ามีเซิร์ฟเวอร์อยู่ที่พอร์ตนั้นแล้ว จะใช้ตัวเดิมและไม่ไปปิดของใคร

ผลลัพธ์: `✓` = ชุดนั้นคืน exit 0 · `✗` = มี `FAILS:` หรือ `ERRORS:` แล้วจะพิมพ์รายละเอียดท้ายสุด

## ย้ายเครื่อง

ที่อยู่ของ Playwright กับ Chromium อยู่ใน `suites/env.js` **ที่เดียว** แก้ตรงนั้น
หรือสั่งทับด้วยตัวแปรสภาพแวดล้อมโดยไม่ต้องแก้ไฟล์:

```bash
QA_PLAYWRIGHT=/path/to/node_modules/playwright \
QA_CHROMIUM=/path/to/chromium \
node tools/qa/run.js
```

ค่าเริ่มต้นคือของกล่องพัฒนาเดิม: `/opt/node22/lib/node_modules/playwright` และ `/opt/pw-browsers/chromium`

## กติกาที่ทุกชุดยึด

1. **ถอดด่านออกแล้วต้องแดง** — ทุกด่านใหม่พิสูจน์ด้วยการลบ guard ทิ้งแล้วดูว่าเทสต์จับได้
   ถ้าลบแล้วยังเขียว แปลว่าเทสต์อ่อน **หรือโค้ดตรงนั้นไม่มีเหตุผลจะอยู่** (เคยเจอกรณีหลังจริง — ดู `docs/04` §9i)
2. **ยิงที่ชั้นที่ของจริงใช้** — สิทธิ์พิสูจน์ด้วยการเรียกฟังก์ชันบันทึกตรง ๆ ไม่ใช่ดูว่าปุ่มถูกซ่อน
3. **ตรวจทั้ง "ต้องมี" และ "ต้องไม่มี"** — เทสต์ที่ตรวจแต่ทางที่ถูก ปล่อยข้อมูลรั่วผ่านได้สบาย
4. เทสต์ไม่แก้ไฟล์ในรีโป ไม่เขียนลงฐานข้อมูลจริง ทุกอย่างอยู่ในหน่วยความจำของหน้าเว็บ

## ข้อจำกัดของกล่องทดสอบ

- **เบราว์เซอร์ออกอินเทอร์เน็ตไม่ได้** (`ERR_CONNECTION_RESET`) ชุดที่ต้องใช้ API จริงจึงดักคำขอด้วย
  `page.route` แล้วป้อน payload ที่เก็บไว้ใน `suites/fixtures/` — ส่วนการยิง API จริงใช้ `curl` แยกต่างหาก
- ชุดที่ใช้กล้องต้องเปิด `--use-fake-ui-for-media-stream --use-fake-device-for-media-stream`
- ทุกชุดตั้ง `timezoneId:'Asia/Bangkok'` · Node พาร์สสตริง ISO เป็น UTC เทียบเวลาจึงต้องคำนวณ**ในหน้าเว็บ**
