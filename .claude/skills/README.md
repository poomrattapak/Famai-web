# Skills ในโปรเจกต์นี้

คัดมาจาก github.com/mattpocock/skills (MIT — ดู LICENSE-mattpocock) 14 ตัวที่เข้ากับงานนี้
**แก้เฉพาะบรรทัด `description`** ให้เด้งกับคำไทยที่ใช้จริงในโปรเจกต์ — เนื้อในไม่แตะ
ตัวที่มี `disable-model-invocation: true` (implement, to-spec, to-tickets, grill-me)
เป็นเจตนาของผู้เขียนว่าให้คนพิมพ์ / เรียกเอง — คงไว้ตามเดิม
issue tracker ของ skill ชุดนี้ = ไฟล์ใน `.claude/issues/`

## ของโปรเจกต์นี้เอง (ไม่ได้มาจากชุด mattpocock)

| skill | ใช้เมื่อ |
|---|---|
| `famai-ship` | รับคำสั่งเจ้าของแล้วจะส่งงานหนึ่งรอบ — ตั้งแต่แยกคำสั่งจนตรวจ production |
| `famai-mutation` | จะพิสูจน์ด่านใหม่ หรือ mutation แล้วด่านยังเขียว |

สองตัวนี้เก็บ**เหตุผลกับกับดักที่เจอจริง** ส่วนกฎถาวรอยู่ `rules/` และคำสั่งรันอยู่ `CLAUDE.md`
เจอกับดักใหม่ให้เติมลงตัวที่มีอยู่ อย่าเปิดไฟล์ใหม่
