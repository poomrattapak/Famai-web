ที่เก็บ ticket/งานค้างของโปรเจกต์ — ใช้โดย skill `/to-tickets` `/to-spec` `/implement`
ไฟล์ละงาน ชื่อ `NNN-ชื่อสั้น.md` · งานที่จบแล้วย้ายเข้า `done/`

**โฟลเดอร์นี้เป็นของทีมพัฒนา — ไม่รวมใน deliverable ที่ส่งลูกค้า**

## รอของจากเจ้าของ (13 ส.ค. 2569)

- [ ] รูปตัวอย่าง 3 รูป: หัวข้อฟอร์มลูกค้า · หน้าขายส่ง · ตัวเลือกสรุปดีล
- [ ] ไฟล์โลโก้ร้าน PNG พื้นหลังใส (D3) — เอกสารเว้นหัวกระดาษรอไว้แล้ว
- [ ] เงื่อนไขเครดิตขายส่ง (F4) — ระหว่างรอ default = เงินสด
- [ ] เรตดอกเบี้ยจริงของแต่ละไฟแนนซ์ (C1) — กรอกเองได้ในตั้งค่า > บริษัทไฟแนนซ์
- [ ] สามอย่างบนหน้าเว็บ Supabase (O5 — เจ้าของสั่งทำทีหลัง): เปลี่ยนรหัสผ่าน DB ·
      เปิด Leaked Password Protection · เติมเบอร์โทรสาขา
