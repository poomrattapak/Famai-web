### 📘 คู่มือการใช้งาน

คู่มืออยู่ที่ `docs/manual/` และเปิดได้จากในแอปเอง — แผ่น **"อื่น ๆ" → ช่วยเหลือ**
พนักงานจะเห็นลิงก์เล่มของบทบาทตัวเองกับเล่ม flow

| ไฟล์ | สำหรับ |
|---|---|
| `famai-admin.pdf` · `famai-manager.pdf` | ผู้ดูแลระบบ · ผู้บริหาร |
| `famai-sales.pdf` · `famai-stock.pdf` · `famai-tech.pdf` | เซลล์ · สต๊อก · ช่าง |
| `famai-acct.pdf` · `famai-hr.pdf` | บัญชี · ฝ่ายบุคคล |
| `famai-flow.pdf` | flow ทั้ง 5 สายงาน ตั้งแต่ต้นจนจบ |

**สร้างใหม่เมื่อระบบเปลี่ยน:**

```bash
node tools/manual/build.js            # เขียนทับ docs/manual/*.pdf
node tools/manual/build.js --no-mask  # ไม่ปิดบังเลขเครื่อง/เลขถัง/เลขบัญชี
```

ตาราง "หน้าจอที่คุณเห็น" กับ "สิ่งที่คุณทำไม่ได้" ดึงจาก `MENU`/`ROLES` ในแอปตรง ๆ
เพิ่มเมนูใหม่แล้วสั่งสร้างใหม่ คู่มือจะตามเอง — ส่วนถ้อยคำอยู่ใน `tools/manual/content.js`
ภาพหน้าจอถ่ายจากแอปจริงที่ความกว้างมือถือ และ**ปิดบังเลขเครื่อง เลขถัง เลขเอกสาร
เลขบัญชี และเลขประกันสังคมให้อัตโนมัติ** ก่อนถ่าย

## v0.9 — ฐานข้อมูลจริงบน Supabase (ไม่ใช่ต้นแบบแล้ว)

สร้างโปรเจกต์ **`famai-motor`** แพ็ก **Free ฿0/เดือน** ที่สิงคโปร์ ลงข้อมูลจริงและต่อกับต้นแบบแล้ว

| | ผล |
|---|---|
| ตาราง | 45 · นโยบาย RLS 59 ข้อ · เปิด RLS ครบทุกตาราง |
| ข้อมูลจริง | รถ 50 คัน · แบบรถ 14 · สี 35 · ราคา 11 · สาขา 3 · บทบาท 7 |
| บัญชีผู้ใช้ | 9 บัญชีทดสอบ (`@famai.local`) — รหัสผ่านส่งในแชต ไม่เก็บในรีโป |
| ขนาด | 12 MB จาก 500 MB |

**RLS พิสูจน์แล้วด้วยการล็อกอินจริง** ไม่ใช่แค่เขียนนโยบายไว้เฉย ๆ

```
แอดมิน 50 คัน · 3 สาขา     เซลล์ FMG01 29 คัน · 1 สาขา
เซลล์ FMM01 14 คัน · 1 สาขา   เซลล์ FCG01 7 คัน · 1 สาขา
ไม่ล็อกอิน → []
```

การกรองเกิดที่**ฐานข้อมูล** — แก้ JavaScript ในเบราว์เซอร์หรือยิง API ตรงด้วย curl
ก็ไม่ได้ข้อมูลสาขาอื่น

**ลองเอง** — เปิดต้นแบบ กด "ใช้ข้อมูลจริงจากฐานข้อมูล" ใต้ปุ่มเข้าสู่ระบบ แล้วกรอกอีเมล/รหัสผ่าน
เชื่อมไม่ได้เมื่อไหร่ (เน็ตหลุด/โปรเจกต์หยุดพัก) จะเด้งข้อความแล้ว**กลับไปโหมดสาธิตเอง** ไม่ค้างไม่พัง
ต้นแบบเรียก REST ตรง ๆ ด้วย `fetch` ไม่โหลดไลบรารีจาก CDN — เปิดแบบ `file://` ออฟไลน์ก็ยังใช้ได้

**เว้นว่างไว้เพราะยังไม่มีของจริง** — เลขผู้เสียภาษีของร้าน (เลขในไฟล์ยามาฮ่าเป็น**ของไทยยามาฮ่า**
ไม่ใช่ของร้าน) · ชื่อบริษัทตามทะเบียน · ที่อยู่ · เบอร์ · เรตไฟแนนซ์ · ข้อมูลพนักงานจริง

SQL ที่รันจริงอยู่ใน `supabase/migrations/` (9 ไฟล์) · วิธีต่อ วิธีเปลี่ยนเป็นผู้ใช้จริง
และตอนไหนต้องอัปเป็น Pro อยู่ใน **`docs/06-supabase-setup.md`**

## เปิดดูต้นแบบ

`index.html` ที่รากคือ **ตัวจริงที่ deploy** — แก้ที่ไฟล์นี้ไฟล์เดียว
`prototype/` เก็บเวอร์ชันเก่า (v0.5 · v0.6 · v0.7) ไว้เทียบเท่านั้น

เปิดจากเครื่องได้ตรง ๆ หรือดูที่ลิงก์ที่ deploy ไว้

### Deploy

รีโปนี้ต่อกับ Vercel ผ่าน Git แล้ว — push แล้ว deploy อัตโนมัติ
`vercel.json` ตั้ง `X-Robots-Tag: noindex` และ `Referrer-Policy: no-referrer` ไว้
เพราะต้นแบบมีเลขเครื่อง เลขถัง และต้นทุนจริง
`.vercelignore` จำกัดสิ่งที่ขึ้นเว็บให้เหลือ `index.html` + `docs/manual/` เท่านั้น —
`reference/` `supabase/` `prototype/` `tools/` `.claude/` เป็นของภายใน ห้ามถูก serve

> ถ้าวันหนึ่งเลิกสมาชิก Vercel Pro ทางสำรองคือ **Cloudflare Pages** (ฟรี ไม่ห้ามเชิงพาณิชย์)
> แลกกับต้อง build เป็น static/SPA และย้ายงานฝั่งเซิร์ฟเวอร์ไป Supabase Edge Functions
