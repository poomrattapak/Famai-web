## สัญญาที่ห้ามหาย (เหตุผลที่ทุกแบบพอร์ตลงของจริงได้)

จาก 61 ชุดใน `tools/qa/suites/` มี **57 ชุดที่แค่กด `#lgGo` เดินผ่านหน้าล็อกอิน** ·
**14 ชุดคลิก `[data-id="STn"]` เจาะจง** · **2 ชุดอ่านข้อความในการ์ด**
⇒ ถ้าเก็บสัญญาข้างล่างไว้ **รื้อหน้าตาทั้งหน้าได้โดยแก้ด่าน 0 ชุด** ทั้ง 10 แบบจึงทำตามนี้หมด

- `#login` ซ่อนด้วยคลาส `.off` · `#app` ถอด `.off`
- `#lgUsers` เป็นที่อยู่ของรายชื่อ · ปุ่มคนมีคลาส `lg-u` + `data-id="ST1".."ST10"` **ครบ 10 เรียงตามลำดับ**
- ปุ่มแรกมีคลาส `on` ตั้งแต่วาดเสร็จ (ไม่ใช่ตั้งตอนคลิก) และมีตัวที่เลือกได้ทีละคนเท่านั้น
- ข้อความในการ์ดรวมกันต้องมีคำว่า **"บัญชี"** (มาจากชื่อ ST7 "นุช บัญชี") และ **"สต๊อก"** (จากชื่อบทบาท)
- มีครบ `#lgGo #lgGo2 #lgSwap #lgEmail #lgPw2 #lgDemo #lgLive`
- การซ่อน `#lgDemo`/`#lgLive` ต้องทำให้ `offsetParent` เป็น `null` จริง (`display:none` ใช้ได้ · `opacity:0` ใช้ไม่ได้)
- **ห้ามซ่อนปุ่มคนด้วย `display:none` ไม่ว่ากรณีใด** — แบบที่กรอง (5) หรือเลื่อน (3, 10)
  ใช้ CSS `order` / `opacity` แทน ปุ่มทุกตัวต้องยังคลิกได้

`common.js` มี `contract()` ที่ตรวจข้อพวกนี้ให้ทันทีที่เปิดหน้า และขึ้นป้ายมุมขวาบนว่าครบหรือหลุด
ทำให้รู้ตั้งแต่ตอนเขียนแบบที่ 7 ว่าแบบที่ 7 หลุดข้อไหน ไม่ต้องรอตรวจรอบใหญ่

## ตรวจ

```bash
node tools/qa/gallery-check.js --cache    # ครั้งแรก: ดึงฟอนต์จาก Google มาเก็บ (ต้องมีเน็ตทาง curl)
node tools/qa/gallery-check.js            # ตรวจทุกหน้า 14 ข้อ × 2 ความกว้าง × 2 ธีม
node tools/qa/gallery-check.js 3 7        # เฉพาะบางแบบ
node tools/qa/gallery-check.js --shots    # + ถ่ายภาพ 40 ใบ ทำแผ่นรวมให้ดูด้วยตา
```

**ทำไมไม่อยู่ใน `tools/qa/suites/`** — `run.js` รันทุกไฟล์ในโฟลเดอร์นั้นอัตโนมัติ แต่ตัวนี้ต้องใช้
แคชฟอนต์ที่ดึงจากเน็ตมาก่อน ถ้าเอาไปวางในนั้นการรันเต็มจะแดงบนเครื่องที่ยังไม่ได้สร้างแคช

**เบราว์เซอร์ในกล่องทดสอบออกเน็ตไม่ได้** จึง `curl` CSS+woff2 มาเก็บที่ `tools/qa/.fontcache/`
(อยู่ใน `.gitignore` ไม่ commit) แล้ว `page.route` ยัดกลับเข้าเบราว์เซอร์ ·
URL ที่ไม่อยู่ในแคช **นับเป็น fail ไม่ใช่เงียบ** เพราะ miss แปลว่าชื่อฟอนต์พิมพ์ผิด —
กลายเป็นตัวสะกดคำให้แทนที่จะเป็นอุปสรรค (ถ้าเปลี่ยน `<link>` ต้องสั่ง `--cache` ใหม่)

## สิ่งที่ตัวตรวจจับได้จริงระหว่างทำรอบนี้

ทุกข้อคือของที่ตาคนมองผ่าน แต่วัดแล้วเจอ

1. สีเทา `--muted` ที่ใช้กันทั่วไปได้คอนทราสต์แค่ **3.0–3.4** ไม่ผ่าน 4.5
2. ธีมมืดพลิกสีกลุ่มเป็นสีอ่อน ตัวอักษรขาวบนวงกลมเหลือ **2.5** → ต้องมี token `--on-grp` ของตัวเอง
   (บทเรียนเดิมของโปรเจกต์: token ที่พลิกตามธีม ห้ามใช้ข้ามบทบาท)
3. ปุ่มแดงในธีมมืดใช้แดงอ่อนกว่า ตัวขาวเหลือ **3.3** → ต้องมี `--on-accent`
4. แท่งกราฟที่ใช้ `--r-pill` กลายเป็น **วงรี** เพราะแท่งเตี้ยกว้าง
5. ประกาศน้ำหนักฟอนต์ใน `<link>` แต่ไม่มีใครใช้ (Chakra Petch 500, Taviraj 500, Prompt 500, Athiti 500)
   — เบราว์เซอร์ไม่โหลด แต่ก็เป็นการประกาศเกินเปล่า ๆ
6. **ฟอนต์ไทย 7 ใน 10 แบบไม่มี tabular figures** — เลข 1 แคบกว่าเลข 8 คอลัมน์เงินจะขยับ
   ผลวัดอยู่ในตารางเทียบบนสารบัญ (อย่าเดา ให้วัด)
