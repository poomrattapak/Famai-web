# สรุปบรีฟ 6 กันยายน 2569

- [ฉบับทีมพัฒนาและปฏิบัติการ — 9 หน้า](Famai-Brief-2026-09-06-team.pdf): ขอบเขต 19 ข้อ ผู้รับผิดชอบ กระบวนการ กฎข้อมูล เกณฑ์ตรวจรับ และข้อเสนอแนะ

สร้างซ้ำ:

```sh
QA_PLAYWRIGHT=/path/to/playwright QA_CHROMIUM=/path/to/chrome node tools/brief/build.js
```
