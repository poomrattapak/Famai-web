## วิธีตีความผล

- ด่าน Chromium ขับแอปจริงในโหมดสาธิตและจำลองคำตอบ API เพื่อทดสอบ pending/error/retry โดยไม่สร้างธุรกรรมจริงในร้าน
- PostgreSQL ชั่วคราว replay migration ทั้ง 35 ไฟล์ ทดสอบ RLS/trigger ด้วย role authenticated/anon และ rollback ทุกครั้ง รวม 98 assertions และ mutation 36 จุด
- งานบริการเพิ่ม mutation หน้าเว็บ 3 จุด: เปลี่ยน UUID เมื่อลองใหม่, ปิดงานก่อนฐานยืนยัน และเพิ่มบริการในเครื่องก่อนฐานยืนยัน ด่านจับได้ทั้งสามและต้นฉบับผ่าน
- บน production ตรวจประวัติ migration, schema, RLS และ EXECUTE ของ RPC ทั้งสามแบบอ่านอย่างเดียว พร้อมตรวจหน้าเว็บหลังเผยแพร่ ไม่มีรหัสผ่านบัญชีพนักงานจริง จึงไม่อ้างการขายจริงผ่านบัญชีเหล่านั้น
- ภาพ 68 ภาพครอบคลุม 1440/390 และธีมสว่าง/มืด ไม่มี pageerror ภาพตรวจอยู่ใน tmp/qa-ci/screenshots ของ workspace
- fixture care-r17 เคยตั้งรายการเริ่มต้น 09:00 ซึ่งเป็นอนาคตเมื่อทดสอบตอนเช้ามืด แก้ข้อมูลเวลาทดสอบให้ใหม่กว่าทุกรายการแล้วตรวจซ้ำผ่าน; ไม่ได้แก้การเรียงจริงให้ยอมรับผลผิด
